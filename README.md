# C Programming Source Code Collection 💻

A comprehensive collection of **C language programs** covering fundamentals, control structures, functions, arrays, strings, structures, file handling, and basic problem-solving concepts.

This repository is ideal for **students, beginners, and practice/reference purposes**.

---

## 📌 Repository Overview

This repository contains multiple standalone C programs that demonstrate:

- Basic syntax and logic building
- Mathematical and logical problems
- Use of functions and recursion
- Arrays, strings, and structures
- Conditional statements and loops
- File handling basics
- Pattern printing and number series

Each file focuses on **one concept or problem**, making it easy to understand and practice.

## 🚀 How to Run Programs

1. Clone the repository:
```bash
git clone https://github.com/Soumya-Das-2006/C-Programming-source-code.git
````

2. Navigate to the folder:

```bash
cd C-Programming-source-code
```

3. Compile any program:

```bash
gcc filename.c -o output
```

4. Run the program:

```bash
./output
```
